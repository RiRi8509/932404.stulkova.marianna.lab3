# Лабораторная работа №3 — Flexbox и CSS Grid

## О проекте

Это адаптивное одностраничное портфолио техногика и обзорщика гаджетов. Проект продолжает ЛР №2: старые разделы сохранены, а к ним добавлены адаптивные блоки на Flexbox и CSS Grid.

Проект сделан на HTML5 и CSS3 без JavaScript, фреймворков и сборщиков.

## Тема

Техногик и обзорщик гаджетов. Визуальное направление: high-tech в чёрной, графитовой и серебристой гамме.

## Цель работы

- Освоить одномерные раскладки Flexbox.
- Освоить двумерные сетки CSS Grid.
- Изменять компоновку через медиазапросы.
- Исключить горизонтальную прокрутку на мобильных устройствах.
- Сохранить семантическую разметку и доступность.

## Реализовано

- Адаптивная Flexbox-навигация.
- Flexbox-секция «Гаджеты недели» из четырёх карточек `article`.
- CSS Grid-секция «Сравнение характеристик».
- Шесть блоков: процессор, экран, батарея, память, накопитель и камера.
- Числовые значения размечены элементами `<data>`.
- Локальные SVG-иллюстрации и содержательные `alt`-описания.
- Видимый фокус для клавиатурной навигации.

## Адаптивная схема

| Ширина экрана | «Гаджеты недели» | «Сравнение характеристик» |
| --- | ---: | ---: |
| от 1200 px | 4 карточки | 3 колонки × 2 строки |
| 768–1199 px | 2 карточки | 2 колонки × 3 строки |
| до 767 px | 1 карточка | 1 колонка |
