# Лабораторная работа №2 - CSS

## О проекте

Это одностраничное портфолио начинающего техногика и обзорщика гаджетов. Страница знакомит с автором, показывает навыки и идеи будущих обзоров, содержит боковую информационную панель и учебную форму обратной связи.

Проект сделан без фреймворков, сборщиков и JavaScript. Основные стили находятся во внешнем файле `style.css`. В `index.html` оставлены один inline-стиль и небольшой внутренний блок CSS, необходимые по заданию.

## Тема

Техногик и обзорщик гаджетов.

Визуальное направление: спокойный high-tech в чёрной, графитовой и серебристой гамме. Дизайн использует строгие линии, металлические оттенки, контрастные светлые поверхности и небольшие холодные акценты.

## Цель работы

- Научиться подключать внешний файл CSS.
- Продемонстрировать внешний, внутренний и inline CSS.
- Использовать CSS-переменные, разные селекторы и псевдоклассы.
- Показать `position: static`, `position: relative` и `position: absolute`.
- Оформить карточки навыков как металлические пластины.
- Обеспечить читаемый контраст и адаптивность страницы.

## Реализовано

- Семантическая структура из `header`, `nav`, `main`, `section`, `aside` и `footer`.
- Первый экран с именем автора, тематическим описанием и локальным аватаром.
- Секция «Навыки» с маркированным списком `ul`.
- Секция «Проекты» с нумерованным списком `ol` из четырёх идей обзоров.
- Отдельная боковая панель «Любимая техника».
- Внутренние навигационные ссылки и внешняя ссылка на GitHub.
- Форма с полями имени, email и сообщения.
- Атрибуты `label`, `name`, `placeholder`, `autocomplete` и `required`.
- Состояния `:hover`, `:active`, `:focus` и `:visited`.
- Металлические карточки с длинной тенью при наведении.
- Видимое свечение кнопки при фокусе.
- Адаптивная компоновка для ноутбука, планшета и смартфона.
- Основной CSS во внешнем файле `style.css`, без внешних библиотек.

### Визуальная проверка

- Отображается шапка и навигация.
- Видны имя, заголовок и описание автора.
- Аватар загружается без значка ошибки.
- В «Навыках» показан маркированный список.
- В «Проектах» показан нумерованный список из четырёх пунктов.
- Боковая панель визуально отличается от секции навыков.
- Форма и footer отображаются полностью.

### Проверка формы

1. В поле «Имя» можно ввести обычный текст.
2. Поле «Email» использует `type="email"`.
3. В поле «Сообщение» можно ввести многострочный текст.
4. У каждого поля есть `label`, `name` и `placeholder`.
5. Кнопка «Отправить сообщение» видна и доступна с клавиатуры.
6. Если оставить поле пустым и нажать кнопку, браузер покажет встроенное сообщение, потому что у полей есть атрибут `required`.
7. Если ввести адрес без символа `@`, браузер попросит исправить email.

Форма не подключена к backend. После проверки браузером данные не попадут владельцу сайта, не сохранятся в базе и не будут отправлены письмом. Для реальной отправки нужен сервер или отдельный сервис обработки форм.
